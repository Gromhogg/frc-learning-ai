CNC MILLING MACHINE OPERATION
Mentor Knowledge Guide — FIRST Robotics Team

SAFETY REQUIREMENTS
Safety glasses are mandatory at all times in the shop. Never reach into a CNC enclosure while the spindle is moving — wait for full stop and confirm the program has ended. Keep hands clear of the tool path during dry runs. Tie back hair, remove jewelry, and wear close-toed shoes. Never override soft limits unless explicitly instructed by a mentor. If the machine behaves unexpectedly, hit the E-stop immediately.

WHAT IS A CNC MILL
A CNC (Computer Numerical Control) mill is a vertical milling machine driven by stepper or servo motors on each axis. Instead of turning handwheels, you load a G-code program and the controller moves the table and spindle automatically to cut the programmed shape. On a manual mill you make every move; on a CNC mill you set up the part, set your work zero, and the machine executes the program.

CONTROLLER BASICS
Most hobby and educational CNC mills use a controller running LinuxCNC, Mach3, or a proprietary interface. The controller reads G-code — a text file of movement and spindle commands. Common codes:
- G0: Rapid move (no cutting)
- G1: Linear feed move (cutting)
- G2/G3: Circular arc (CW / CCW)
- G54–G59: Work coordinate system (where your part zero is)
- M3/M5: Spindle on / off
- M6: Tool change
- F: Feed rate in IPM or mm/min
- S: Spindle speed in RPM

SETTING WORK ZERO
The work zero (also called WCS or G54 origin) is the reference point the program measures from. Typical workflow:
1. Load your stock and clamp it securely.
2. Use an edge finder or electronic touch probe to locate the corner or center of the stock.
3. Jog to that position, then zero the work coordinate in the controller (G54 X0 Y0).
4. Touch off the top surface of the stock for Z zero. Use a paper feeler or electronic probe.
5. Store the Z offset. Never manually jog below Z0 when a program is loaded.

TOOL LENGTH OFFSETS
Each tool has a different length. The controller needs to know each tool's length offset so it knows where the tip actually is. Measure offsets with a tool length probe or by touching off each tool to a known surface and recording the offset in the tool table. Programs reference tools by number (T1, T2…); the controller applies the offset automatically.

FEEDS AND SPEEDS — SAME RULES AS MANUAL
RPM = (SFM × 3.82) / tool diameter
Feed rate (IPM) = RPM × chip load × number of flutes

The CNC does not protect you from wrong feeds and speeds. A too-fast feed will break the tool; a too-slow feed will rub and work-harden steel or melt aluminum. Always verify speeds and feeds in your CAM post-processor before running.

RUNNING A PROGRAM
1. Load the G-code file into the controller.
2. Do a dry run with the spindle off and the Z axis raised 1–2" above the part — watch the X/Y motion match your expected toolpath.
3. Confirm work zero and tool offsets are set.
4. Set feed rate override to 50% for the first pass.
5. Start the program. Stand at the E-stop and watch the first cut carefully.
6. Increase feed override gradually if cuts look and sound healthy.

COMMON PROBLEMS
Chatter: Reduce depth of cut, increase feed rate, or use a shorter tool stick-out.
Tool breakage: Check offsets, feeds/speeds, and chip evacuation. Aluminum chips packing into a pocket will break tools.
Missed steps (stepper machines): The motor lost position. The part is now scrap. Home the machine and restart.
Program crashes into clamps: Review the CAM setup — clamps must be modeled or avoided in the toolpath.

FIXTURING FOR ROBOTICS PARTS
Aluminum plate stock: Use a vise or toe clamps. Always face the top surface first for a reliable Z reference.
Thin sheet: Double-sided tape on a sacrificial spoilboard, or use tabs in the CAM program to keep the part from moving on the last cut.
Round stock: Use a vise with V-blocks or a chuck mounted to the table.

MACHINE MAINTENANCE
Check lubrication on linear rails and ball screws before each use. Chip evacuation: brush or vacuum chips before they pack into ways. Never use compressed air to blow chips toward the controller or electrical cabinet. Wipe down the table after each job.
