CAM — COMPUTER-AIDED MANUFACTURING
Mentor Knowledge Guide — FIRST Robotics Team

WHAT IS CAM
CAM (Computer-Aided Manufacturing) is the process of turning a 3D CAD model or 2D sketch into machine instructions — G-code — that tell a CNC mill, CNC router, or waterjet what path to follow and at what speed. The CAM software simulates the tool cutting the material and outputs a file the machine controller can read. Getting CAM right means parts come out on-size the first time; getting it wrong means broken tools, scrapped material, or damaged machines.

CAM SOFTWARE WE USE
Fusion 360 (Autodesk): Full-featured CAM integrated with 3D CAD. Free for hobbyists and FIRST teams. Good for CNC milling operations on aluminum robotics parts.
Onshape + CAM Add-ons: Some CAM tools (e.g., Kiri:Moto) run as Onshape add-ons. Convenient for simple 2.5D work without leaving Onshape.
Carbide Create / VCarve: Common for CNC router operations, especially for wood and polycarbonate sheet work.
OMAX Layout / FlowPath: Dedicated software for waterjet. Handles kerf compensation, lead-ins, and abrasive settings automatically.

THE CAM WORKFLOW
1. Import geometry: Start with a 3D model (STEP, F3D) or 2D DXF. The geometry must be clean — no open loops in sketches, no overlapping lines.
2. Set up the stock: Define the raw material block (width, height, thickness) and its position relative to your part.
3. Set work zero (WCS): Match your CAM origin to where you will physically set zero on the machine. Typical choices: front-left-top corner or center-top of stock.
4. Select operations: Choose the types of cuts you need (facing, pocketing, contouring, drilling — see below).
5. Set tools: Select or create the end mill or drill you will use. Enter exact dimensions from the tool's spec sheet.
6. Set feeds and speeds: Enter RPM and feed rate. CAM software can suggest starting values; always verify against the material and tool manufacturer's recommendations.
7. Simulate: Run the simulation to check for gouges, collisions with clamps, or missed material.
8. Post-process: Export to G-code using the correct post-processor for your machine (each controller has a different dialect).
9. Run on the machine: Always verify with a dry run before cutting.

COMMON OPERATIONS
Facing: A large-diameter tool sweeps across the top of the stock to create a flat, consistent surface. Always face raw stock before other operations — it establishes your Z reference.
2D Pocket: Clears material inside a closed profile to a specified depth. Used for pockets, slots, and recesses. Set the step-down (how much depth per pass) and step-over (how much width per pass).
2D Contour: Cuts along the outside profile of a part. Typically the last operation — cut the perimeter after all interior features. Add tabs (small bridges that hold the part to the stock until the last pass) if the part will come loose.
Drilling: Spot drill first at low feed, then drill to depth. Set peck depth to clear chips from deep holes.
Bore: Circular interpolation (G2/G3) to finish a hole to tight tolerance. Better than drilling for bearing fits.
3D Adaptive (Fusion 360): Efficient roughing strategy that maintains constant tool engagement. Faster and easier on tools than traditional pocket clearing. Use for complex 3D parts.

TOOL SETUP IN CAM
Define each tool with:
- Diameter (exact — a 1/4" end mill worn to 0.248" will leave your part oversize by 0.002" on a radius)
- Flute count
- Cutting length (how deep the flutes go)
- Overall length (to check clearance)
- Shank diameter

Fusion 360 has a tool library — build a library of the tools you own so you don't re-enter them for every job.

FEEDS AND SPEEDS IN CAM
RPM = (SFM × 3.82) / tool diameter
Feed rate (IPM) = RPM × chip load × flute count

For 6061 aluminum with a 1/4" 2-flute carbide end mill:
SFM: ~400
RPM: ~6,100
Chip load: ~0.002"
Feed rate: ~24 IPM

Start conservative (50–75% of calculated values) and increase based on how the machine sounds and what the chips look like. Proper aluminum chips are small, shiny curls. If you see fine dust, you're rubbing. If chips are blue or the tool smells, you're overheating.

DEPTH AND RADIAL ENGAGEMENT
Axial depth of cut (DOC): How deep each pass goes. For roughing, typically 0.5–1× tool diameter. For finishing, 0.005–0.010".
Radial engagement: How much of the tool width is cutting. Slotting (100% engagement) is hardest on tools — reduce DOC significantly. Adaptive/trochoidal paths limit radial engagement to 10–30% of the tool diameter, allowing much deeper axial passes and longer tool life.

CLIMB vs. CONVENTIONAL MILLING
Climb milling: The tool rotates into the feed direction. Better finish on aluminum, reduces cutting forces with rigid setups. Use for finishing passes.
Conventional milling: The tool rotates against the feed direction. More forgiving on sloppy fixturing; use for roughing on less-rigid setups.

SIMULATION — DO THIS EVERY TIME
Before posting to G-code, run the simulation at full speed, then again in slow motion through any tight sections. Look for:
- Tool gouging into the part (removes too much material)
- Tool collisions with the vise or clamps
- Rapid moves that plunge into material (should retract first)
- Toolpath extending off the edge of the stock

POSTPROCESSORS
The same G-code toolpath means different things to different controllers. A Fusion 360 post for a Haas is not the same as one for a Tormach or a Shapeoko. Always use the correct post-processor. If your machine isn't listed, use a generic GRBL post for hobby machines or contact the manufacturer for their recommended post. A wrong post-processor is a common cause of machine crashes on the first run.

TIPS FOR ROBOTICS PARTS
Thin plates warp from cutting forces — use tabs and support the part with a spoilboard underneath.
Bolt hole patterns: Model bolt hole locations precisely in CAD, drill spot first, then drill to final size in CAM — do not trust a contour cut for hole location.
Chain and belt clearance holes: Slightly oversize (add 0.010–0.020") for easy assembly without sloppy tolerances.
After waterjet: Waterjet holes are tapered — if a hole is a bearing bore or pivot, model it intentionally undersized and finish-drill/ream in the CNC after waterjet cutting.
